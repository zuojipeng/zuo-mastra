# Sprint 2 Release Notes

Date: 2026-05-18

## Completed

- Added a formal refinement request contract for partial prompt optimization.
- Supported refinement targets for full prompt, negative prompt, timeline segment, platform variant, and version.
- Updated the frontend to send structured `refinement` payloads instead of embedding target content only in free text.
- Added a pending refinement state in the UI so users can see and cancel the active partial optimization target.
- Added a lightweight frontend smoke test for build output.
- Updated frontend and backend README files.

## Verification

- Backend: `npm run check` passed.
- Frontend: `npm run lint` passed.
- Frontend: `npm run build` passed.
- Frontend: `npm run test:smoke` passed.

## Known Issues

- Partial optimization still returns a full result envelope; dedicated side-by-side version comparison is not implemented yet.
- History detail, search, and saved project organization are still pending.

## Next Iteration
